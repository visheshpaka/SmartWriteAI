# SmartWrite AI 🤖

## Overview
SmartWrite AI is an AI-powered tool for effortless blog generation, leveraging advanced language models from Hugging Face. It helps users generate high-quality blog content, including creative title suggestions and full blog posts, based on the given inputs. The tool features an intuitive interface built with Streamlit, enabling easy customization of blog topics, keywords, audience type, and word length.

## Features
- **Title Generation**: Generates 10 creative blog title suggestions for the given topic.
- **Blog Content Generation**: Creates plagiarism-free blog posts with an introduction, body, and conclusion, following a conversational writing style.
- **Interactive Interface**: User-friendly interface built with Streamlit for an engaging experience.
- **Customizable Options**: Allows users to specify blog topics, audience types (Beginner, Intermediate, Expert), keywords, and target word count.
- **Keyword Management**: Facilitates adding and removing keywords for more tailored blog generation.

## Tech Stack
- **Python**: The core programming language used for scripting.
- **Streamlit**: Framework for creating the interactive user interface.
- **LangChain**: For prompt management and chaining the language model.
- **Hugging Face Hub**: Utilizes the "Mixtral-8x7B-Instruct-v0.1" model for AI-driven text generation.
- **Environment Variables**: Securely handles API keys for Hugging Face integration.
